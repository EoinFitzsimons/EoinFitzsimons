## Selected Projects

### Momentum — Motorsport Management System

[Repository](https://github.com/EoinFitzsimons/Final-Project) · Final Year Individual Project

A motorsport management system supporting driver archetypes, race simulation and standings progression, built with Python and PyQt6.

* Translated user requirements into system features and workflows, including the race progression logic
* Designed a modular architecture separating the GUI, application and data layers
* Wrote 11 unit tests, 7 class tests and 1 integration test with pytest and pytest-qt (19/19 passing), alongside manual system testing mapped to every functional requirement
* Authored an 88-page technical report covering requirements, architecture and key algorithms with pseudocode and complexity analysis
* Completed a separate ethical and sustainability evaluation of the design against the ACM Code of Ethics

**Technologies:** Python · PyQt6 · JSON · pytest

### Daytona 400 — Give(a)Go Hackathon Project

[Repository](https://github.com/EoinFitzsimons/GiveaGoDaytona)

An AI-agent-driven generation and evaluation pipeline built at a hackathon.

* An agent selected design parameters, Daytona executed and validated the output in an isolated sandbox, and the results fed back into the next iteration
* Geometry generation, validation and scoring logic ran across four hundred circuit evaluations
* A PyQt6 monitoring interface showed execution, results, parameters, scores and AI feedback per iteration

**Technologies:** Python · Groq · Daytona · PyQt6

### IoT Sensor Collection and Analysis System

IoT Fundamentals and Developments project (85.4%)

* A Raspberry Pi with a Sense HAT collected temperature, humidity and pressure readings, applied CPU-heat compensation and published over MQTT at fixed intervals, storing every reading locally in SQLite to survive connection loss
* A consumer application validated incoming payloads, persisted the last one hundred readings to JSON and produced Matplotlib charts and statistical summaries
* Verified stable acquisition at roughly 0.52-second intervals

**Technologies:** Python · Raspberry Pi · Sense HAT · MQTT · SQLite · Matplotlib
